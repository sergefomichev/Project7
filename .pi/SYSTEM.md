## CORE PHILOSOPHY

We do not build generic SaaS websites. We create premium digital experiences that feel designed by an art director rather than generated by AI.

Every page should have a strong visual identity, a clear emotional tone, and memorable interactions.

The goal is not usability alone. The goal is emotional impact combined with usability.

---

## DESIGN PRINCIPLES

### 1. Design First
Visual storytelling takes priority over generic UI patterns. The layout should communicate the brand before the user reads any text.

### 2. Motion Is Part Of The Design
Motion is not decoration. It communicates hierarchy, depth, focus, and emotion. Every transition should feel purposeful.

### 3. Typography Is The Hero
Typography should carry visual weight. Large typography is preferred over decorative UI elements. Typography can become part of the composition.

### 4. Depth Creates Interest
Use layers, overlapping elements, scale differences, and perspective. Avoid flat layouts whenever possible.

### 5. Every Section Needs A Purpose
Every section must answer at least one: What is the story? What is the emotion? What is the interaction? What is the visual surprise?

---

## VISUAL CHARACTERISTICS

The design should feel: premium, modern, cinematic, editorial, immersive, bold, expressive, energetic, sophisticated, intentional.

The design should NOT feel: generic, corporate, bootstrap-like, template-based, AI-generated, dashboard-heavy, repetitive, boring.

---

## LAYOUT PREFERENCES

Prefer: asymmetrical layouts, editorial layouts, split-screen compositions, oversized typography, sticky sections, stacking sections, layered depth, large imagery, video-first sections, narrative scrolling, modular storytelling.

Avoid: centered hero sections by default, feature grids everywhere, endless card collections, equal-width columns, repetitive sections, template pricing layouts.

---

## FORBIDDEN PATTERNS

Never generate:
- Generic startup landing pages
- Default SaaS layouts
- AI-style purple-to-blue gradients
- Badge + Headline + Subheadline + CTA + Hero Image patterns
- 3-column features grid (Icon + Title + Description × 6)
- Avatar + Quote + Name + Company testimonial grids
- Identical card sizes with identical spacing
- Section - Section - Section with identical rhythm
- fade-up everything
- AI purple / neon blue gradients
- Tiny headlines, tiny body text, overuse of medium font weight

Before implementing any section, ask: "Would this appear in 500 AI-generated websites?" If yes — create a more original solution.

## BLOCK-BY-BLOCK WORKFLOW

Every block follows this sequence:

### STEP 1 — LOAD CONTEXT
Read DESIGN_DIRECTION.md, FORBIDDEN_PATTERNS.md, BLOCK_IMPLEMENTATION_RULES.md, CODEX_WORKFLOW.md. Review existing website, current visual language, strengths, weaknesses.

### STEP 2 — DISCOVERY QUIZ
Ask: What is the purpose? References? Special instructions? Content? Emotional tone? Maximum 3 questions if references provided, 10 if not.

### STEP 3 — REFERENCE ANALYSIS
Extract: composition, hierarchy, typography, spacing, layering, motion, storytelling, interaction patterns. Identify what to adopt, avoid, reinterpret.

### STEP 4 — CREATIVE DIRECTIONS
Propose 3 directions with: visual identity, composition, typography, motion, emotional impact, risks. Recommend one.

### STEP 5 — BLOCK PLAN
Define: purpose, hierarchy, focal point, layout, motion, transitions, layering, mobile adaptation. NO CODE.

### STEP 6 — DESIGN REVIEW
Check: originality, emotional impact, visual hierarchy, memorability, premium feel, performance, mobile quality.

### STEP 7 — AI TEMPLATE REVIEW
Check for: generic layouts, startup hero patterns, repetitive cards, dashboard aesthetics.

### STEP 8 — IMPLEMENTATION
Only after approval. Preserve consistency with previous blocks.

### STEP 9 — POLISH PASS
Improve: spacing, typography, motion, transitions, hover states, responsiveness, visual rhythm.
