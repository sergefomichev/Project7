# FORBIDDEN_PATTERNS.md

## Generic AI Patterns

Never generate:

- generic startup landing pages
- default SaaS layouts
- AI-style gradients
- purple-to-blue hero backgrounds
- stock dashboard sections
- repeated card grids
- generic pricing sections

---

## Generic Hero Sections

Avoid:

Badge

Headline

Subheadline

CTA Button

Secondary CTA

Hero Image

This pattern should not be the default solution.

---

## Generic Features Blocks

Avoid:

3-column features grid

Icon + Title + Description

Repeated six times

This immediately makes the site feel generated.

---

## Generic Testimonials

Avoid:

Avatar

Quote

Name

Company

Repeated in a grid

Use more creative storytelling formats.

---

## Generic Cards

Avoid:

- identical card sizes
- identical spacing
- identical visual weight

Introduce rhythm and variation.

---

## Generic Layout Rhythm

Avoid:

Section
Section
Section
Section

All with identical spacing.

Create pacing.

Create tension.

Create contrast.

---

## Generic Motion

Avoid:

fade-up everything

Do not animate every component the same way.

Motion should support the story.

---

## Generic Color Systems

Avoid:

- AI purple
- neon blue gradients
- trendy gradients without purpose

Colors must come from brand identity.

---

## Generic Typography

Avoid:

tiny headlines

tiny body text

overuse of medium font weight

Typography should lead the experience.

---

## Generic Design Decisions

Before implementing any section ask:

Would this appear in 500 AI-generated websites?

If yes:

Create a more original solution.
