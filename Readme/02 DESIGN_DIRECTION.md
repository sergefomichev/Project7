# DESIGN_DIRECTION.md

## Project Philosophy

We do not build generic SaaS websites.

We create premium digital experiences that feel designed by an art director rather than generated by AI.

Every page should have a strong visual identity, a clear emotional tone, and memorable interactions.

The website should feel intentional, editorial, cinematic, and crafted.

The goal is not usability alone.

The goal is emotional impact combined with usability.

---

## Core Design Principles

### 1. Design First

Visual storytelling takes priority over generic UI patterns.

The layout should communicate the brand before the user reads any text.

### 2. Motion Is Part Of The Design

Motion is not decoration.

Motion communicates hierarchy, depth, focus, and emotion.

Every transition should feel purposeful.

### 3. Typography Is The Hero

Typography should carry visual weight.

Large typography is preferred over decorative UI elements.

Typography can become part of the composition.

### 4. Depth Creates Interest

Use layers.

Use overlapping elements.

Use scale differences.

Use perspective when appropriate.

Avoid flat layouts whenever possible.

### 5. Every Section Needs A Purpose

Every section must answer at least one question:

- What is the story?
- What is the emotion?
- What is the interaction?
- What is the visual surprise?

If a section does none of these things, redesign it.

The design should feel:

- premium
- modern
- cinematic
- editorial
- immersive
- bold
- expressive
- energetic
- sophisticated
- intentional

The design should NOT feel:

- generic
- corporate
- bootstrap-like
- template-based
- AI-generated
- dashboard-heavy
- repetitive
- boring

---

# Layout Preferences

Prefer:

- asymmetrical layouts
- editorial layouts
- split-screen compositions
- oversized typography
- sticky sections
- stacking sections
- layered depth
- large imagery
- video-first sections
- narrative scrolling
- modular storytelling

Avoid:

- centered hero sections by default
- feature grids everywhere
- endless card collections
- equal-width columns
- repetitive sections
- template pricing layouts

---

# Visual Hierarchy Rules

Use contrast aggressively.

Create hierarchy through:

- scale
- spacing
- motion
- opacity
- weight
- composition

Avoid relying only on color.

# Animation Philosophy

Animations should feel:

- physical
- smooth
- intentional
- premium

Preferred techniques:

- parallax
- masks
- reveals
- clip-path transitions
- sticky interactions
- stacking sections
- scroll-driven animation
- kinetic typography
- image sequence effects
- subtle 3D transforms

Avoid:

- random floating elements
- excessive bounce
- unnecessary rotations
- distracting motion

---

# Mobile Philosophy

Mobile is not a scaled desktop.

Design dedicated mobile compositions.

Reposition elements when needed.

Maintain emotional impact.

Maintain visual hierarchy.

Never simply shrink everything.
