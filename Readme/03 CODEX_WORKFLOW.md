# CODEX_WORKFLOW.md

## Step 1

Never start coding immediately.

First propose:

- 3 visual directions
- 3 interaction directions
- 3 motion directions

No code.

Only concepts.

---

## Step 2

Create a page architecture.

Explain:

- storytelling flow
- visual rhythm
- transitions between sections
- emotional journey

No code.

---

## Step 3

Create an art direction board.

Describe:

- typography
- spacing
- visual hierarchy
- color palette
- motion language
- imagery style

No code.

---

## Step 4

Implement the chosen direction.

Use existing components when available.

Do not create duplicate UI patterns.

---

## Step 5

After implementation perform Design Review.

Review:

- typography
- spacing
- composition
- motion
- visual balance
- mobile experience

Identify weak areas.

Improve them.

---

## Step 6

Perform Creative Review.

Ask:

Does this feel handcrafted?

Does this feel premium?

Does this feel memorable?

Does this feel different from a template?

Would it stand out on Awwwards?

If the answer is no:

Iterate again.

---

## Step 7

Perform AI Detection Review.

Identify:

- generic layouts
- repeated sections
- repetitive cards
- common AI patterns
- weak visual hierarchy

Replace them.

---

## Step 8

Perform Polish Pass.

Improve:

- transitions
- hover states
- microinteractions
- typography rhythm
- spacing rhythm
- visual tension
- visual depth

Only after this stage consider the design complete.
